## 一、这是什么

「麦麦吃饭小搭子」是一个跑在 WorkBuddy 对话里的**治愈系麦当劳点餐 Agent Skill**。

它解决的不是"能不能点餐"，而是**"站在柜台前看了三分钟菜单还是不知道点什么"**这件更真实的事：

- 想控卡，但 `522 kcal` 到底是多少？——它会换算成 **`≈ 2 碗饭`** 让你有概念
- 想省钱，但 35 块怎么配最划算、有没有券能叠？——它去查**你这家店真正能用的券**再配
- 发工资想吃顿好的，但选择太多？——它按"有排面"的逻辑挑贵的
- 就是想吃某几样，懒得算钱？——它实时算价，加一样算一次

所有价格都来自麦当劳 MCP 的 `calculate-price`，**没有一个数字是编的**。

### 四条路线（主菜单）

```
A. 🥒 今天想当一根薯条　（→ 轻一点，瘦一点）      控卡轻食：按热量 + 蛋白质配
B. 🥔 月底了，麦门低保　（→ 省一点，活下去）      省钱：按搭配骨架 + 券 + 预算配
C. 🍅 发工资了，朕要奢侈（→ 贵一点，爽一点）      犒劳：有排面的组合
D. 🌶️ 别管我，我自己来　（→ 自由一点，随我心意）  自由点单：分类菜单 + 实时结算
```

## 二、目标用户

| 人群 | 痛点 | 小搭子怎么解决 |
|---|---|---|
| **控卡 / 减脂人群**（非专业健身） | 知道要看热量，但 `kcal` 没有体感 | 热量换算成"几碗饭"，并给运动参照 |
| **月底省钱党 / 学生** | 预算固定，不知道券怎么叠最划算 | 先问搭配骨架 → 再定预算上限 → 券后实付价 |
| **选择困难症** | 菜单太长，越看越不知道自己想吃什么 | 一条消息问完、全流程只需"回一个字母" |
| **赶时间的上班族** | 点个餐要来回问七八轮 | 用餐方式 + 门店合并成一问，最多两轮进菜单 |
| **长期麦当劳用户** | 想发现新品和隐藏搭配 | 结合营养数据 + 官方 500 大卡套餐分类推荐 |

## 三、快速开始

### 前置条件

1. 安装 **腾讯 WorkBuddy**（[官网](https://www.workbuddy.cn/?fromSource=gwzcw.22245487.22245487.22245487&utm_medium=cpc&utm_id=gwzcw.22245487.22245487.22245487)）
2. 拥有 **麦当劳 MCP Token**（[申请方式](https://github.com/M-China/mcd-mcp-server)）

### 第 1 步：配置麦当劳 MCP 连接器

打开 WorkBuddy → 左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置 MCP】，
填入 `mcp-config.example.json` 的内容，**把 `${MCD_MCP_TOKEN}` 换成你自己的 Token**，保存后【启用】。

> ⚠️ 本仓库的示例配置**只含环境变量占位符**，不含任何真实 Token。

### 第 2 步：安装本 Skill

把本仓库的 `skill/` 目录整个复制到 WorkBuddy 用户技能目录：

```bash
# macOS / Linux
cp -r skill ~/.workbuddy/skills/mcd-dining-buddy

# Windows (PowerShell)
Copy-Item -Recurse skill "$env:USERPROFILE\.workbuddy\skills\mcd-dining-buddy"
```

也可以直接对 WorkBuddy 说：**「帮我把这个仓库的 skill 目录安装成本地技能」**。

安装后的目录结构：

```
~/.workbuddy/skills/mcd-dining-buddy/
├── SKILL.md                        # 主文件：人设、排版规范、四场景流程、红线
├── references/
│   ├── healing-lines.md            # 治愈短句池 / 时段问候语 / 冷笑话 / 颜文字
│   ├── mcd-mcp-tools.md            # 麦当劳 MCP 工具契约、参数、坑位、降级方案
│   └── card-templates.md           # 封面牌 / 选项菜单 / 方案表格 / 卡片模板
└── assets/
    └── cover.html                  # 带 CSS 动画的封面页
```

### 第 3 步：开一个新会话，说「麦麦吃饭小搭子」

Skill 在会话开始时加载，**装完请新开一个会话**。

## 四、使用示例

### 示例 1 · 控卡（说「麦麦吃饭小搭子」→ 回 `A` → 回 `A + D`）

```
两个小问题一起回我就行，比如「B + 南京西路」🏪

【怎么吃】
A. 🏪 到店自取　（去店里拿，最省配送费）
B. 🛵 麦乐送　　（送到你手上）
C. 🚗 得来速　　（开着车顺路取）

【在哪吃】
D. 🏠 就用我的收藏店（麦当劳上海杨浦创智天地下壹站餐厅）
城市 / 商圈 / 店名直接打字告诉我就好～
```

选完之后直接出方案表（价格全部来自 `calculate-price`，热量来自 `list-nutrition-foods`）：

| 方案 | 搭配 | 热量 | 实付 |
|---|---|---|---|
| A · 板烧轻盈 | 板烧鸡腿堡 + 纯牛奶（盒装）+ 锡兰红茶 | 522 kcal ≈ 2碗饭 | ¥46.00 |
| B · 深海清爽 | 双层深海鳕鱼堡 + 锡兰红茶 | 487 kcal ≈ 2碗饭 | ¥36.00 |
| C · 官方 500 大卡 | 「苹板」支撑Pro套餐 | 476 kcal ≈ 2碗饭 | ¥39.50 |

> 🌿 A：蛋白质 29g，嘴不委屈、腰也不内疚
> 🌿 C：麦当劳自己就算好了，你只管吃——最省心的选择

### 示例 2 · 月底省钱（回 `B`，搭配与预算一次问完）

```
【怎么搭】
A. 🍔+🍟+🥤 汉堡+薯条+饮料　B. 🍔+🥤 汉堡+饮料　C. 🍔+🍟 汉堡+薯条
D. 🍟+🥤 小食+饮料　E. 🌶️ 我自己说

【预算】（上限，不是要花完）
F. 💰 20 元以内　G. 💰 20–30 元　H. 💰 30–40 元　I. ✨ 不设上限
```

假设回 `A + G`：

| 方案 | 搭配 | 券 | 实付 |
|---|---|---|---|
| A · 极致省 | 双层吉士汉堡 + 无糖可乐(中) | 满20减6 | ¥18.50 |
| B · 带份薯条 | 双层吉士汉堡 + 中薯条 + 无糖可乐 | 满30减9 | ¥25.00 |
| C · 三件套保底 | 巨无霸 + 中薯条 + 无糖可乐 | 满30减9 | ¥31.00 |

### 示例 3 · 自由点单（回 `D`）

菜单按**三张小表**平铺，不再是一张翻不完的大表：

```
🍔 主食          🍟 小食            🥤 饮料
| 餐品 | 价格 |   | 餐品 | 价格 |    | 餐品 | 价格 |
| 巨无霸 | ¥25.0 | | 大薯条 | ¥14.0 | | 无糖可乐 | ¥9.0 |
```

之后每加一样，实时调 `calculate-price` 出小票卡片。

## 五、设计亮点

这套 Skill 的每一条设计，都来自真实使用后的返工：

| 设计 | 为什么这么做 |
|---|---|
| **热量带"几碗饭"参照** | `kcal` 对非健身人群是乱码，参照物才是信息。基准统一 `1 碗饭 ≈ 230 kcal` |
| **全流程"回一个字母"** | 需要用户回话的地方一律给 A/B/C 选项，打字成本降到 1 个字符 |
| **选项必须自解释** | 选项里直接写"方案名 + 搭配 + 价格"，不写"第一个/第二个"——不许让用户往上翻 |
| **预算只当上限，不当靶心** | 你说 35 块，输出是 ¥18 / ¥25 / ¥31 三档，而不是三个都贴着 34.9 |
| **用餐方式 + 门店一条问完** | 拆成三轮是客服，合成一轮才是搭子。有收藏店时 `A + D` 一步进场景 |
| **菜单拆三张小表** | 单表条目太多翻着累；主食 / 小食 / 饮料各一张，每类最多 8 款 |
| **下单三态确认** | 「随便」不算确认；无明确确认不下单 |
| **工具不可用就说不可用** | 宁可说"价格我不敢乱报"，也不编数字 |

## 六、安全与合规

- 仓库内**不含任何真实 Token / 密钥 / 凭证**，配置示例仅用 `${MCD_MCP_TOKEN}` 占位符

- 下单等不可逆操作**必须用户明确确认**，且不做自动重试

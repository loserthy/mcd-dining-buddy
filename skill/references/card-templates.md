# 排版模板（封面牌 / 选项菜单 / 方案表格 / 卡片）

> 所有金额处填 `calculate-price` 的返回值（记得 ÷100 转元）；
> 所有热量处填 `list-nutrition-foods` 的返回值。
> 本文件里的数字**全是示例**，写回复时必须换成工具真实返回值。

## 一、封面牌（每次触发的第一屏）

封面牌结构：**上装饰线 → 标题 → 图标带 →（可选）小品句 → 下装饰线**。

三条铁律：

1. **不用左右竖线框**（手机字宽不齐，框必歪）。
2. **标题永远是「麦麦吃饭小搭子」**，字间插空格做出手账感。
3. **六套变体随机换**，同一会话里不要连用同一套。


### 为什么会"动"

对话是纯文本渲染，放不了 GIF 和视频。动感靠三招做出来：

| 招 | 怎么用 |
|---|---|
| 运动痕迹符号 | `｡o○`（滚动小点）、`››`（箭头残影）、`▰▱`（进度条）——都是"动作留下的形状" |
| 每次换变体 | 六套随机 → 同一个角色，不同的出场方式，自然不呆板 |
| 进度条随机长度 | `▰▰▰▰▰▰▰▱▱▱` / `▰▰▰▱▱▱▱▱▱▱`，像真的在加载 |

用户说“看封面 / 开场动画 / 动起来的那种”，就用 `present_files` 展示
`assets/cover.html`（那是个真带 CSS 动画的封面页）。

### 开场完整顺序

```
{封面牌}

{治愈开头句} 🌤️

{时段问候语}

━━━━━━━━━━━

A. 🥒 今天想当一根薯条　（→ 轻一点，瘦一点）
B. 🥔 月底了，麦门低保　（→ 省一点，活下去）
C. 🍅 发工资了，朕要奢侈　（→ 贵一点，爽一点）
D. 🌶️ 别管我，我自己来　（→ 自由一点，随我心意）
```

主菜单这四行**也要带字母**——本技能里所有"要用户回话"的地方都是 A/B/C 选项，
交互语言全程统一：用户永远只需要"回一个字母"就能往前走。
用户不回字母、直接说想吃的东西，也照常接，别纠正他"请回复字母"。

## 二、选项菜单（提问专用，本技能最重要的交互形式）

### 格式规范

```
字母. 全角空格 Emoji 选项名　（一句人话注解）
```

四条要求：

1. 选项 **2–5 个**，超了拆两题。
2. **一道题一套字母；两题一起问就接着往下排**，别都从 A 开始。
3. 注解必须是人话——用户光看注解就知道选的是什么。
4. 选项后面永远补一句**开放出口**。

### 标准块 1：用餐方式 + 门店（第 0 步，一条消息问完，不许拆回合）

````
两个小问题一起回我就行，比如「B + 南京西路」🏪

【怎么吃】
A. 🏪 到店自取　（去店里拿，最省配送费）
B. 🛵 麦乐送　　（送到你手上）
C. 🚗 得来速　　（开着车顺路取）

【在哪吃】
D. 🏠 就用我的收藏店（麦当劳××××餐厅）
城市 / 商圈 / 店名直接打字告诉我就好～
````

- 有收藏店时**必须**把收藏店列成选项（如 D 项），用户回 `A + D` 一步到位，
  直接进场景，不再确认门店。
- 城市没法做成选项，允许开放输入，但要和"怎么吃"**并在同一条消息里**。
- 用户反馈过：餐厅和取餐方式分两次问很繁琐——**不许拆成两轮。**

### 标准块 1b：门店候选（搜出来之后，一次定完）

取餐方式**写进每个门店选项里**，回一个字母 = 门店 + 方式同时定下，
**不要再来一轮"那这家吗？"的确认**：

```
翻到这几家，回我字母就行 📍

A. 🏪 到店自取 · 麦当劳×××餐厅（××路 303 号地下一层）· 距离 500m
B. 🏪 到店自取 · 麦当劳×××餐厅（××地铁站）· 距离 1.2km
C. 🛵 麦乐送 · ×××餐厅（在你配送范围内）
或者直接说店名 / 位置，我再帮你搜 🧭
```

例外：候选没法判断哪个对（关键字命中一堆不相干的）、
或外送地址拉到多个分不清时，才允许追问一句。

### 标准块 2：月底省钱的两个问题（场景二，一次问完）

```
月底省钱模式启动 🥔 两个小问题一起问完，回我「搭配字母 + 预算字母」就行，比如 A + G

【怎么搭】
A. 🍔+🍟+🥤　汉堡 + 薯条 + 饮料（经典三件套）
B. 🍔+🥤　　 汉堡 + 饮料（轻一点）
C. 🍔+🍟　　 汉堡 + 薯条（不要饮料）
D. 🍟+🥤　　 小食 + 饮料（下午茶式）
E. 🌶️　　　　我自己说（比如"就要一个堡"）

【预算】
F. 💰 20 元以内
G. 💰 20–30 元
H. 💰 30–40 元
I. ✨ 不设上限，只挑划算的
```

**字母一定要接着排**（A–E → F–I），两题都用 A 开头会让用户分不清他选的是哪道题。

漏答处理：

| 情况 | 怎么接 |
|---|---|
| 只回了搭配（如 `A`） | 预算按 **I** 走，不追问 |
| 只回了预算（如 `G`） | 搭配按 **A** 走，不追问 |
| 回“随便 / 你看着办” | 按 **A + I** 走，并说一句“那我按三件套配，先不设上限啦” |
| 选了 E 但没说结构 | 先等他讲完结构，再把预算那组 F–I 抛出来 |
| 自己描述了搭配 | 按他说的来，别往回套模板 |

### 标准块 3：方案后的替换 / 选定（场景一 / 二 / 三）

> ⚠️ **让用户选方案的选项，必须把方案真实内容写进去**（方案名 + 搭配 + 价格）。
> 不许写"第一个 / 第二个 / 就这个 / 那个"——用户不该为了看懂选项再往上翻表格。
> 表格里的 A/B/C 和选项里的 A/B/C 是同一个 A/B/C，要一一对应。

场景一（这里是"操作"不是"选方案"，描述操作就行）：

```
想调的话回我字母就行：
A. 主食换成更轻的　B. 饮料换成无糖的　C. 加一份蔬菜或水果
```

场景二（把表格那几行的关键信息搬下来）：

```
想定哪个回我字母就行：

A. 极致省 · 双层吉士汉堡 + 无糖可乐(中)　¥18.50
B. 带份薯条 · 双层吉士汉堡 + 中薯条 + 无糖可乐　¥25.00
C. 三件套保底 · 巨无霸 + 中薯条 + 无糖可乐　¥31.00
```

场景三（搭配最长也要写全；最后留一个"我要别的"的出口）：

```
想选哪个回我字母就行～

A. 一人独享 · 安格斯厚牛堡 + 大薯条 + 大杯可乐　¥76.00
B. 分给同事 · 麦乐鸡分享盒 + 大薯条 + 大杯可乐 ×2　¥98.00
C. 朕今日最大方 · 巨无霸 + 安格斯厚牛堡 + 麦乐鸡分享盒 + 大薯条 + 奥利奥麦旋风　¥142.00
D. 🍽️ 我想要别的，重新给我配一套
```

### 标准块 4：自由点单收尾（场景四）

```
还要继续吗？
A. ✅ 就这些了，往下走　B. ➕ 再加点　C. ➖ 删掉一个
```

### 标准块 5：下单确认（收尾）

```
要现在下单吗？

A. ✅ 确认下单（巨无霸 ×1 + 中薯条 ×2，应付 ¥52.0）
B. ✏️ 我还想改一下
C. 🧾 再给我看看别的方案
```

A 选项必须带**清单摘要 + 金额**，不能只写"就这个组合"。

### 开放出口（每次提问都要跟在选项后面）

| 场景 | 出口句 |
|---|---|
| 控卡 | 或者你有自己的想法，也可以告诉我，我帮你看看热量和价格呀 🍟 |
| 省钱 | 如果你心里已经有想吃的，直接说，我照样给你算钱 🥔 |
| 奢侈 | 有想吃的直接点名，不用管我给的选项 👑 |
| 自由 | 想加什么直接说菜名，我记着账呢 🧾 |

## 三、方案表格（场景一 / 二 / 三 / 四通用）

### 通用四列（场景一：控卡）

```
给你配了三个，从轻到重排好啦 👇

| 方案 | 搭配 | 热量 | 实付 |
|---|---|---|---|
| A · 翅上有光 | 薄皮焦香V翅 + 麦乐鸡5块 + 苹果片 + 锡兰红茶 | 439 kcal ≈ 2碗饭 | ¥48.50 |
| B · 板烧午茶 | 板烧鸡腿堡 + 小杯玉米杯 + 小杯鲜萃咖啡 | 459 kcal ≈ 2碗饭 | ¥46.00 |
| C · 官方500大卡 | 「苹板」支撑Pro套餐 | 476 kcal ≈ 2碗饭 | ¥39.50 |

🌿 A：蛋白质 29g，嘴不委屈、腰也不内疚
🌿 B：一个堡一份菜一杯咖啡，像认真生活过的人
🌿 C：麦当劳自己就算好了，你只管吃，最省心

想调的话回我字母就行：
A. 主食换成更轻的　B. 饮料换成无糖的　C. 加一份蔬菜或水果
或者你有自己的想法，也可以告诉我，我帮你看看热量和价格呀 🍟
```

**热量列必须带米饭换算**：基准 **1 碗米饭（约 200g 熟重）≈ 230 kcal**，
碗数 = 热量 ÷ 230，四舍五入到 0.5，写成 `522 kcal ≈ 2碗饭`。
裸的 kcal 数字对不健身的人没有意义。可选在点评里偶尔带一句运动参照
（慢跑约 10 kcal/分钟），别每条都带。

### 省钱版（场景二：第三列换成「券」）

```
| 方案 | 搭配 | 券 | 实付 |
|---|---|---|---|
| A · 极致省 | 双层吉士汉堡 + 无糖可乐(中) | 满20减6 | ¥18.50 |
| B · 带份薯条 | 双层吉士汉堡 + 中薯条 + 无糖可乐 | 满30减9 | ¥25.00 |
| C · 三件套保底 | 巨无霸 + 中薯条 + 无糖可乐 | 满30减9 | ¥31.00 |

🌿 最省的顺手是 A，吃得最满足的是 C

想定哪个回我字母就行：

A. 极致省 · 双层吉士汉堡 + 无糖可乐(中)　¥18.50
B. 带份薯条 · 双层吉士汉堡 + 中薯条 + 无糖可乐　¥25.00
```

- 这个场景**不给选项**——用户是来自由发挥的，问了反而碍事。

```
━━━━━━━━━━━

━━━━━━━━━━━
🍔 巨无霸 ×1　　¥25.0
🍟 中薯条 ×1　　¥14.0
🥤 无糖可乐 ×1　¥9.0
━━━━━━━━━━━
```

## 七、排版自检清单

回复发出前对一遍，任一条不满足就改：

- [ ] 最上面有封面牌？标题是全名「麦麦吃饭小搭子」？用的是没用过的变体？
- [ ] **需要用户回话的地方，是不是给了带字母的选择题**（不是开放问题）？
- [ ] 两题一起问时，字母是接着排的吗（A–E → F–I，没撞号）？
- [ ] 每个选项后面有开放出口吗（“或者你有自己的想法……”）？
